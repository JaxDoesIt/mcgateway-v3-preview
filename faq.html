FAQ / 01

Getting started

What is MCGateway?

A free community-run Minecraft Bedrock gateway. Add an MCGateway access bot, join MCGateway Hub from Friends, then choose a destination server.

Is it free?

Yes. Joining servers through MCGateway is free. Donations and optional services for server owners are separate.

Which platforms are supported?

Xbox, PlayStation, Nintendo Switch, Windows, mobile, and other supported Minecraft Bedrock devices.

Do I need to download anything?

No extra console app or DNS changes. You add a friend account through Minecraft or supported Xbox account interfaces.

Which bot should I use?

Pick any bot marked Available on the live Bots page. You need only one.

How long does a friend request take?

Usually 20 to 30 seconds, sometimes up to roughly a minute.

FAQ / 02

Joining & transfers

How do I join a custom server?

Add an available bot, join MCGateway Hub through Minecraft Friends, open the Hub menu with the robot or Ender Pearl, and enter a valid Bedrock IP and port.

Why is MCGateway Hub not showing up?

Check that you added the exact gamertag and waited for acceptance. Restart Minecraft if the Friends list has not refreshed, or try another available bot.

Why did a transfer fail?

The destination might be offline, have an incorrect port, be Java-only, require an allowlist, or have other normal server restrictions.

What is a Server Code?

A short MCGateway code that represents a server address. Request one for free through a ticket in the official Discord.

Can I request a Server Code for a server I do not own?

Yes. Request it through Discord with the server name, IP, port, and desired code.

FAQ / 03

Hub & accounts

Can MCGateway remember my servers?

Yes. Saved servers, favorites, recent servers, and Auto Join are supported Hub features.

What is Auto Join?

A feature that automatically directs you toward your selected saved server when entering the Hub.

Does MCGateway need my Microsoft password?

No. Never give a password to an access bot or MCGateway support.

Will bots remove inactive friends?

They may remove inactive friends after roughly a month to keep capacity available. Simply add an available bot again when you return.

What can I do in MCGateway Hub?

The Hub is primarily for choosing and transferring to Bedrock servers. It also has infinite parkour and a PvP arena to try while you are there.

FAQ / 04

Support & privacy

Where do I report an issue?

Use the official Discord for help, or email mcgatewaycontact@gmail.com.

Does MCGateway publish private server destinations?

No. Private destinations are not automatically listed publicly merely because they appear in service history.

Does MCGateway sell player information?

No. For more details, see the Privacy page.
