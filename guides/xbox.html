START HERE

Two ways to add a bot.

Choose one method. Both lead to the same MCGateway Hub; they are alternatives, not two steps you need to complete.

OPTION ARECOMMENDED

From inside Minecraft

Open Minecraft, find the access bot through cross-platform Friends, and join the Hub without leaving the game.

Follow the pictured walkthrough
OPTION BALTERNATE

Through Xbox People

Search for the same MCGateway gamertag from your Xbox console first, then return to Minecraft and join the Hub.

Show Xbox People instructions
  1. Find your recommended bot gamertag in the live bot card in Step 4.
  2. Press the Xbox button, open the People area, and find the player-search option.
  3. Search for the recommended bot and choose Add Friend.
  4. Open Minecraft and continue at Step 6 to find the Hub in Friends.
PART ONE · STEPS 1–6

Get into MCGateway Hub.

Follow these steps if you're adding the bot from inside Minecraft. If you chose Xbox People instead, start at Step 6 once you've added the bot.

01 / 02
01
STEP 1

Open Minecraft on your Xbox

From your Xbox dashboard, find Minecraft and launch it. These instructions use Minecraft Bedrock on Xbox One, Series S, or Series X.

02
STEP 2

Select Play

Once Minecraft finishes loading, choose Play from the main menu. You do not need to start a world first.

03
STEP 3

Open the Friends tab

On the Play screen, move to the Friends tab. This is where you can find cross-platform friends and join their worlds.

04
STEP 4

Search for an access bot

Choose the player-search or Find Cross-Platform Friends option, then enter the recommended bot shown below exactly as written. The name comes from the live recommendation in this step.

If the account is not currently verified as available, use the full bot list instead.

STEP 5

Add the bot as a friend

Open the matching profile and select Add Friend or Send Friend Request, depending on the wording shown on your version. Once the request has been sent, return to Minecraft's main menu.

06
STEP 6

Join the MCGateway Hub

Give the bot a moment to add you back, then open Play → Friends again. Find the joinable world named MCGateway Hub, hosted by the recommended bot, and choose Join.

The world may take a short time to appear after you send your friend request.

Not popping up after 60 seconds?

Try these checks in order:

  1. Confirm the account actually shows as a friend, not only as a pending request.
  2. Close and reopen the Friends tab to refresh the joinable worlds.
  3. Check the live bot fleet and try adding one or two other available bots.
  4. Restart Minecraft and check again.
  5. Make sure your Microsoft/Xbox account allows cross-network multiplayer.

If the Hub still does not show, ask for help in MCGateway Discord.

PART TWO · STEPS 7–10

Connect to your server.

Once you're inside the Hub, the remaining steps are the same whichever method you used to add the bot.

02 / 02
07
STEP 7

Find the robot or use the Ender Pearl

After the Hub loads, walk forward toward the robot near the spawn area. You can also use the provided Ender Pearl to open the Hub menu.

08
STEP 8

Open the menu and choose how to connect

Interact with or punch the robot to open the menu, unless you already opened it with the Ender Pearl. Choose Add Server to use a Bedrock IP address and port, or choose Server Code if someone specifically gave you a code for their server.

A Server Code is not something you need to create for a normal IP and port connection.

09
STEP 9

Enter your server details

Follow the option you selected in the menu.

IF USING AN IP ADDRESS

Add Server

Enter a name to recognize the server, the Bedrock server IP/address, and its port. The usual Bedrock port is 19132, but use a different port if the server owner provides one.

IF YOU WERE GIVEN A CODE

Server Code

Choose Server Code and enter the exact code you received. You only need this route if that server specifically uses a code.

10
STEP 10

Save the server, then join!

Select Add to Server List to save your entry. Find the server in your Hub server list, select it, and choose Join to transfer to your destination.

If the transfer fails, double-check the Bedrock address and port. The destination server must be online and allow the connection.

NEED A HAND?

A few common questions.

Can't find the recommended bot?

Check that you're searching for the exact Xbox gamertag inside Minecraft's cross-platform friend search. If availability is unverified or the bot is full, choose another available account from the live bot list.

The Hub is visible, but joining fails.

Confirm Minecraft is updated, retry joining the world, and check that online multiplayer and cross-network play are enabled. If the issue persists, try a different available bot or ask in Discord.

Can I connect to any Minecraft server?

The destination needs to support Bedrock connections or provide compatible Bedrock access. A Java-only address by itself will not necessarily work.

Still stuck? Our community can help you troubleshoot in MCGateway Discord.
