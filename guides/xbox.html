YOUR FOLLOW-ALONG GUIDE

From the home screen to your server.

Follow these steps on Xbox One, Series S, and Series X. Everything you need to join is explained below.

BEFORE YOU BEGINMinecraft Bedrock, Microsoft/Xbox multiplayer permissions, and any subscription your console requires.
Find the HubAdd a serverGet help
FIRST, CHOOSE ONE METHOD

Two ways to add a bot.

These are two alternatives, not two steps you need to complete.

OPTION A · RECOMMENDED

Inside Minecraft

Use the cross-platform Friends search and follow the numbered guide below.

Start the walkthrough
OPTION B · ALTERNATE

Through Xbox People

Add the same gamertag from Xbox People, then continue in Minecraft.

Show this method
  1. Find the recommended gamertag in Step 4.
  2. Press the Xbox button and open People.
  3. Search for an available bot and add it as a friend.
  4. Launch Minecraft and continue at Step 6.
PART ONE · STEPS 01–06

Get into MCGateway Hub.

Follow these steps for the in-game friend-search method. If you added the bot through Xbox People, go to Step 6.

01
STEP 01

Open Minecraft

Open Minecraft from your Xbox dashboard.

02
STEP 02

Select Play

On the Minecraft main menu, select Play. You do not need to create or enter a world.

03
STEP 03

Open the Friends tab

In the Play screen, select the Friends tab. This shows joinable friend worlds and cross-platform friend tools.

04
STEP 04

Search for the recommended bot

Choose the cross-platform player search from Minecraft's Friends tab. Enter an available MCGateway bot, exactly as shown in the recommendation below.

Enter the exact gamertag above. The name in this walkthrough updates with the recommendation.

Xbox People is another way to add the same gamertag. See the alternate method above.

05
STEP 05

Add the bot as a friend

Open the bot's profile and choose Add Friend or Send Friend Request, depending on your version.

06
STEP 06

Join MCGateway Hub

Allow about a minute for the bot to add you back. Return to Play → Friends and select MCGateway Hub, hosted by the recommended bot. Choose Join.

Not showing up after 60 seconds?
  1. Check the account is actually a friend, not only a pending request.
  2. Close and reopen Minecraft's Friends tab.
  3. Try one or two other accounts marked Available on the bot list.
  4. Restart Minecraft and double-check multiplayer permissions.
PART TWO · STEPS 07–10

Connect to your destination.

Once you're in the Hub, the process is the same on every console.

07
STEP 07

Find the robot or Ender Pearl

Once inside the Hub, move toward the robot near spawn. You can also use the provided Ender Pearl to reach the menu.

08
STEP 08

Open the connection menu

Interact with or punch the robot, or use the Ender Pearl to open the Hub menu. Select Add Server for IP and port or Server Code if someone supplied a code.

09
STEP 09

Enter your server details

Choose the connection type that matches the information you have.

IP ADDRESS + PORT

Add Server

Enter a recognizable server name, the server's Bedrock IP address, and its port. The normal Bedrock port is 19132; change it if the server uses another port.

ONLY IF YOU HAVE A CODE

Server Code

If the server owner gave you a Server Code, choose that option and enter the code exactly. You do not need a code when connecting by IP and port.

10
STEP 10

Save the server and join

Select Add to Server List, find the entry in your Hub server list, then choose it and select Join. If the transfer fails, check the address, port, and destination availability.

QUESTIONS & TROUBLESHOOTING

Need a hand?

Can I add the bot using Xbox People?

Yes. Search for the same gamertag through Xbox People, add it, then open Minecraft's Play and Friends tabs.

Why can't I see MCGateway Hub?

Make sure the bot accepted your request, refresh Friends, and try another verified available bot. Restarting Minecraft can refresh joinable worlds.

Does this work with Java-only servers?

The destination must accept Bedrock players. Java-only servers need compatible cross-play access.

Do I need to change DNS settings?

No. Join through Minecraft Friends, then use MCGateway Hub's connection menu.

Still stuck? Ask for help in MCGateway Discord.

Menu wording and platform multiplayer requirements can change with Minecraft and console updates.
